# SCENT NOTE

> 향수 쇼핑 웹사이트 | 웹 디자인·퍼블리싱 / 프론트엔드 포트폴리오

## 프로젝트 소개
향수의 향조와 분위기를 살펴보고 원하는 제품을 찜하거나 장바구니에 담을 수 있는 쇼핑형 웹사이트를 제작했습니다. 감성적인 비주얼과 제품 탐색의 편의성을 함께 고려했습니다.

## 사용 기술
React · Vite · JavaScript · CSS · React Router · Lucide React · localStorage

## 주요 작업 내용

### 01. 메인 페이지
향수 슬라이드와 무드별 소개, 취향 테스트 영역을 구성했습니다.

### 02. 상품 목록
향수 8종 데이터를 활용해 검색, 향조 필터, 정렬, 관심 상품 기능을 연결했습니다.

### 03. 상품 상세
제품 설명, 수량 선택, 공식 제품 링크를 배치했습니다.

### 04. 장바구니
상품 담기·삭제·수량 변경과 합계 계산을 구현했습니다.

### 05. 주문 확인
선택한 상품과 금액을 다시 확인하는 화면을 제작했습니다.

### 06. 공통 UI
고정 장바구니·TOP 버튼과 이미지 오류 처리를 적용했습니다.

## 작업하면서 익힌 내용
상품 목록과 상세 화면에서 같은 데이터를 사용하는 구조를 연습했습니다. 수량 변경과 합계 계산 로직을 분리하고, 찜·장바구니 데이터를 localStorage에 유지하는 방법을 익혔습니다.

## 프로젝트 정리
브랜드 분위기를 살리면서 실제 쇼핑몰에서 자주 사용하는 탐색·선택·장바구니 흐름을 구현한 프로젝트입니다.
